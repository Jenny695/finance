# 净值与费用多维评分（zhiheng-investor-4.0）

面向投资者的保留/剔除原则、维度解释和缺项算例见[指标筛选与评分规则](investor-score-policy.md)。Excel只作字段和单位核对依据，日常仍由iFinD接口查询。

普通投资者主查询使用五个目标维度：净值增长25%、回撤控制25%、波动稳定20%、收益风险效率15%、费用负担15%。前四项来自同一条有效净值序列，费用独立评价。不把“收到236个字段名”当成“236项都有有效数据”。

| 维度 | 映射规则 |
|---|---|
| 净值增长 | clip(50+500×区间净值变化) |
| 回撤控制 | clip(100−500×最大净值回落) |
| 波动稳定 | clip(100×(1−每期涨跌样本标准差/阈值))；日3%、周7%、月15% |
| 收益风险效率 | clip(50+25×区间变化/最大回落)；零回落不送效率满分 |
| 费用负担 | 管理/托管/销售服务费各自映射clip100×(1−费率/阈值)，阈值3%/0.5%/1%，子项权重70/20/10 |

clip为截断0—100，输入比率为小数。费用缺项不当零，按已知子项归一计算费用参考分；费用维度有效权重=15%×费用子项覆盖率。例如管理/托管两项返回，费用有效权重为13.5%，销售服务缺失不会被当成免费。完整年费合计只有三项全齐时给出，否则只显示“已知固定年费至少”。交易费、绩效报酬不混入固定年费，也不从已费后净值再次扣费。这些映射与权重为公开自建参数，不是行业分位或购买评级。

综合参考分=Σ(有效分×有效权重)/有效权重合计。真实零分计入；缺项跳过不补分。三维以上画有效轴雷达，一至二维用柱图，零维不造图。数据不足不会保证完整五维分。信用、完整赎回、到账和费用阶梯合同条款不在现有字段中，不凑成评级。

## 复权、恒定值与实际日期

优先使用有足够观测且变化的官方复权单位净值；不足时选用可解释的单位净值。累计单位净值和复权因子仅作补充，不把累计净值等同分红再投资总回报。至少20条/30天，采样稀疏不评回撤/波动/效率；年化仍遵守90天/30条规则。

恒定单位净值**和恒定复权净值**均不产生收益风险高分，可能为重复快照或产品未更新；保留事实，不声称一定是哪一种。所有评分标明实际有效日期。已知分红未复权时停相应净值评分。成立以来收益、当前相对前高回撤只是静态事实，不能替代选定期间收益/最大回撤。费用可独立观察，不能伪装成完整多维评价。

## 236项审阅与24项活跃查询

完整逐字段筛选理由见[236字段审阅表](indicator-selection-236.json)。本次236项保留21项，另沿用之前3个收益风险指标，合计24项。排除基金经理/公司指数、重复排名、复杂回归/尾部条件、ESG、份额/持有人统计等；不把公司、经理指数或前十大持有人占比当作当前产品表现/持仓集中度。

- 核心5项：单位、复权、累计净值、复权因子、最大回撤。
- 费用6项：管理、托管、销售服务、认购、申购、赎回。后3项参数101原样保留，只代表对应条件，不补造全部阶梯规则。
- 收益3项：年化收益、年度分红、成立以来复权增长率。
- 风险3项：年化波动、下行风险、当前相对前高回撤。
- 效率3项：之前提供的年化夏普、索提诺、卡玛。
- 配置4项：股票、债券、基金、存款占净资产比例。配置图只按明确单位与同日数据画柱，不归一成100%，允许杠杆下超过100%，不拿资产类别打安全分。

6类分7个有界请求（每次<=8字段）；基础净值和新增复权分开，避免新增字段权限失败把基础组也带失败。默认查询这24项，清楚提示额度，空值不重试、连续错误暂停。历史档案保留，移除字段不再请求。

## 单位与隐藏

带%/％的费率/比例可自动识别。纯数字不按大小猜单位；零在两种单位下相同可识别。用户确认“1.5代表1.5%”或“0.015代表1.5%”后，可在**当前报告重算**，不请求同花顺、不增查询次数。费率与配置单位分别设置；新导入文件和换产品重置自动识别，不套用其他产品的费率。区间字符串和未明确条件不编成单一值。

“--”、N/A等缺失标记不算有效数据，界面自动隐藏；零值保留。无效日期、结构化异常仍隔离，不吞错。只显示实际有效维度/字段，不为图形填零。导出JSON保留来源和缺项状态。

## 超级命令结果表导入

支持10MB内单表XLSX（实际Excel但后缀CSV也可），最多2000条日期，必须一只产品且日期不重复。识别中文/英文字段名，不执行公式、文件文本或代码。浏览器记录文件SHA256，经本机JSON接口映射到24项；原始文件不上传Git。来源明确标“用户导入、未再次联网核验”，官方链接仅提供方入口，不冒充本次网络请求。

`POST /api/analysis/import-workbook`生成私有报告；`POST /api/analysis/units`仅改报告单位重算。二者都不触发上游请求，继续遵守本机Host/Origin与凭据指纹隔离。数据导入后可直接看有效读数，费用在单位确认后按已知项目观察。若日期列只是重复最新净值，不当成动态历史。

真实导出样本审阅已在私有.local/review保存：236指标、18条日期、17非空字段且全部在日期间恒定；筛选后8个有效读数，无法据此形成完整历史表现评分。费用原值没有百分号，不宣称接口已确定单位；只有单位假设验证，没有冒充已核验产品总评级。真实值不提交公共仓库。要完整历史维度，需要同一产品实际更新日期对应的历史净值，增加静态字段不能替代。

`全部基金.xlsx`的27490条一直属于fund（公募基金），不是券商资管。`全部(已成立、未到期)`的32966条此前因文件名不明确暂归other；本次用户确认并核对全表J类代码、资管产品名称，改为broker（券商资管）。实际数据库类别变为银行148867、公募27490、券商32966、信托139618，总348941，不删除产品来隐藏分类问题。other仅是未知产品的后备类别，当前实际数为0。

新原文件准备器将该明确目录归broker，支持含下划线/连字符的J类代码；其他尚未确认类别的合法代码保留为待分类，不阻止整表导入，也不把任意.OF视为基金或券商。明确目录中已存在的同代码优先保留明确分类并去重。旧包升级时仅识别带正确原文件名、unexpired.csv且全表J类代码（含下划线/连字符）的other目录，重新导入为broker；其他未知类别保留。安装回执版本升级触发一次分类修正，目录导入不联网，不扣iFinD额度。保留.env、整个.local及历史指标和报告，入库前先备份。
