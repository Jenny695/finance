# 普通投资者指标筛选与评分规则

日常流程是产品搜索 → iFinD授权查询 → 有效指标分组 → 维度分与综合参考分。Excel结果表用于检查字段、原始数值、缺失标记和单位；不要求用户日常通过Excel导入。

## 五个评分维度

所有维度满分100。以下比率按小数参与计算，clip表示把结果限制在0至100；阈值为平台自建规则，不声称是行业评级或同类分位。

|投资者的问题|维度与默认权重|计分规则|
|---|---|---|
|这段时间赚了多少？|收益表现（净值增长）25%|r=期末净值/期初净值−1；clip(50+500r)。例如区间收益−10%/0%/+10%对应0/50/100分。|
|历史最深跌过多少？|回撤控制25%|D为同区间最大回撤的正数幅度；clip(100−500D)。回撤0%/10%/20%对应100/50/0分；恒定净值不按零风险评分。|
|持有过程起伏多大？|波动稳定20%|s为每期收益样本标准差；clip[100(1−s/L)]。日度L=3%，周度7%，月度15%；不把每期波动说成年化波动。|
|承担回落换来了多少收益？|收益风险效率15%|clip(50+25r/D)。比值−2/0/2对应0/50/100分；没有观察到回撤则此维不评分，不补满分。|
|持有成本高不高？|费用成本（费用负担）15%|管理/托管/销售服务费各按clip[100(1−费率/阈值)]，阈值分别3%/0.5%/1%；子项权重70/20/10。缺项跳过，费用有效权重=15%×子项覆盖率。|

前四维使用同一有效净值路径，优先复权净值；不是四份相互独立的风险证据。各指标越大未必越好，收益、回撤、费用方向分别处理。不同产品类别、日期窗口、复权与分红口径或有效覆盖率的产品不直接按分数排名。

## 保留、辅助展示与剔除

- 保留24项活跃字段，准确名单见`lib/investor-indicators.js`。净值为计算基础；最大回撤、收益、波动、下行风险、夏普/索提诺/卡玛等原始指标用于核对与解释。不能把未经窗口核对的静态原值直接混入同区间评分。
- 资产配置四项有效时画比例图，回答钱投向哪里；不把债券比例高自动评为安全。分红、当前回撤、成立以来收益作为补充事实，不能替代本期收益与区间最大回撤。
- 管理、托管、销售服务费参与费用评分；认购、申购、赎回费显示对应条件，不直接加进固定年费。费后净值不再重复扣费。
- 净值复权因子和累计净值保留作核验依据，不单独评分。净值绝对值、基金份额、资产规模、久期不按大小打优劣分。
- 基金经理/基金公司指数、重复同类排名、ESG、Alpha/Beta等回归字段、偏度/峰度、条件未清的VaR/CVaR等不在默认查询清单。其余236项档案保留筛选记录，不为了画图而全量调用。
- 完整赎回窗口、锁定期和到账时间需对应产品原文；当前字段不够时不编一个流动性分。普通分散投资者的组合相关性也需要多产品共同历史，不能从一只产品推断分散效果。

## 综合分、隐藏与图表

综合参考分=Σ(有效维度分×有效权重)/Σ有效权重。缺项不当零；真实零分保留。费用缺项会缩小其有效权重，不能把未知销售服务费算作免费。

例如收益80、回撤60、费用90（费用三项齐全），其他维度无依据：综合分=(80×25+60×25+90×15)/65=74.62，覆盖率65%，有3个可评维度。页面同时显示每一维本次归一占比和贡献分，最终计算采用未四舍五入数值。

三维及以上画只包含有效轴的雷达图；一至二维画条形图。综合分旁显示可评维度数与权重覆盖率；只有一维时称单项观察分。有效指标按用途分组，空指标、空分类不铺在页面上；不补造数值、不为完整五边形填零。

## 单位与这份结果表的结论

费率/比例若含百分号则识别百分数；纯数字不根据大小猜小数或百分数。Excel的数字显示格式也不等于接口字段单位。净值是每份价格而非百分比，夏普等比率无百分比单位，资产比例不能与金额混合。

本次结果表没有为全部纯数字费率提供明确百分号格式，不能仅靠文件认定单位。通过终端明确单位后，保存的报告可本地重算，不必再次请求接口。`--`不是零；静态重复日期值不是已核验的动态历史；日期列不自动等于报告期或披露日。单项无数据不妨碍其他已核验维度评分。


## 4.1：披露频率与页面展示

产品分析按实际有效日期识别交易日、自然日、周度或月度披露，不再因类别模板频率错误或正常长假中的单个长间隔停掉三个净值维度。判定同时检查整体观测密度和最长缺口，不插值、不补净值；明显长时间缺失仍不能评回撤、稳定与效率。主页面只展示产品、观察区间、综合分、有效维度图、指标走势与有效配置。计算贡献、覆盖率、公式和数据异常归入折叠的评分依据，原始值和来源归入指标详情。设置、历史和导入工具默认折叠；无效指标隐藏。只有一个有效维度时按该维度名称显示评分，不将它伪称多维综合分。
