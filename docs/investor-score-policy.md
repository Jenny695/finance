# 投资者研究规则

当前版本为 **zhiheng-investor-5.0**，具体计算规则、数据口径与决策约束见[完整说明](simple-scoring.md)。

平台采用三层分析：

1. **七维研究分**：收益20%、回撤20%、稳定15%、风险收益效率15%、下跌防御10%、回撤修复10%、费用10%。缺项跳过、真实0分保留，按有效权重归一。
2. **历史风险画像**：多期收益、回撤和修复、下行偏差、历史VaR/ES、滚动持有体验、同类统计和配置/久期解释。
3. **持有决策参考**：投资者自设的风险预算、期限与仓位约束，新增/持有/退出分别检查。高综合分不能覆盖风险或仓位超限，不按单一分数自动发出买卖指令。

每个有效原始字段都标明参与哪个维度，或为何只作辅助。官方统计在单位和数学含义明确时可独立支持维度；默认统计窗口不伪装成所选净值区间。空风险等级、空指标、空图表隐藏；技术说明和公式折叠。31项字段、8类9组查询，产品对比与综合分析共享服务，不额外要求类别模板。
