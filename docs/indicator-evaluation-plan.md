# 七维评估、指标接口与测试结果

核查日期：2026-10-28（北京时间）。本次没有取得真实产品授权数据；不能将下面的程序测试理解成真实金融结论。

## 实际测试结论

- 现有环境Node24.19，支持本机SQLite。程序测试覆盖83项参数解析、七维要求、零/负值/空值、ESG文本、结构异常隔离、数据库保存、查询边界及评分隔离。
- 用户提供的长函数有83个不重复字段、83组参数。代码目录逐项保留年度2026、编码100/101/102及基准000001.SH，不将它们猜成日期窗口、百分比或评级。
- 当前云端没有`.env`，IFIND_REFRESH_TOKEN和IFIND_ACCESS_TOKEN均未注入；环境配置中已有的个人Token要求也未绑定。没有请求用户再次在聊天发送Token。
- `npm run probe:ifind -- --live`的真实运行结果是`blocked-credentials`、`attempted:false`、`queryCalls:0`，退出码2。报告保存在本机忽略路径`.local/ifind-probe-report.json`。这是“尚未执行”，不是“所有字段不可用”。
- 官方公共示例、手册与无鉴权端点连接尝试没有得到官方响应。curl检查出现`CONNECT tunnel failed, response 403`，属于当前网络代理拒绝，不能称为iFinD返回的业务403或账号权限拒绝。未绕过代理或关闭TLS。
- 隔离测试采用明确标注的上游响应桩，写入/tmp临时库，验证前端/后端链路。真实产品行情库不混入这些测试数据。

## 确定的HTTP映射

用户提供的是THS_DS，因此已提供的83项统一映射至：

`POST https://quantapi.51ifind.com/api/v1/date_sequence`

首次只测净值、最大回撤、久期，不带未知枚举参数，也不将一个月样本用于长期评分：

```json
{
  "codes": "YH0000434.YH",
  "startdate": "20260916",
  "enddate": "20261016",
  "functionpara": {"block": "latest", "Fill": "Blank"},
  "indipara": [
    {"indicator": "ths_unit_nv_fund", "indiparams": [""]},
    {"indicator": "ths_max_retrace_rate_all_fund", "indiparams": [""]},
    {"indicator": "ths_portfolio_duration_fund", "indiparams": [""]}
  ]
}
```

access_token请求头仅由后端添加；refresh_token只用于官方get_access_token换取请求头Token。不要把凭据放到上述JSON、前端或聊天。

basic_data_service是已知官方只读接口类别，但本次没有证实其费用、赎回、管理人字段，故不能编造字段发送。公开文件读取仍使用原有官方HTTPS白名单、robots、限频及大小限制；结构化资料不全时保留缺项。

## 分层测试方法

1. 无需授权：83项解析与参数对齐、请求预览、边界检查、计算基准、类型与存储测试。
2. 有授权后：在本机“指标方案与实测”选择真实代码、类别、日期及一组1—8项，确认额度后执行一次组合查询。不自动测试全83项，不自动重试。
3. 请求成功后：逐字段查看有值/空缺/格式异常/结构待适配，检查是否有区间外日期。原值保留正负号与文本；对象/数组不强行转数值。
4. 语义核验：依据官方指标说明确认单位、窗口、采样、基准、评级参数、报告期、实际披露日和适用产品。即便所有字段有值，此步未完成也不自动评分。
5. 用总回报数据独立复算收益和回撤，对相同窗口及频率下的官方指标进行比较；差异须先查口径，不能相互替代或简单平均。

银行理财YH0000434.YH是原函数样本，不代表债券基金、股票基金或所有银行理财都支持同一字段。其他类别可以在测试工具输入代码实查，但不能提前断言适用。

## 本机执行

网页打开“指标方案与实测”，或项目目录命令行：

```sh
npm run probe:ifind
npm run probe:ifind -- --live
npm run probe:ifind -- --live --code YH0000434.YH --category bank --start 2026-09-16 --end 2026-10-16 --batch starter
```

第一条仅输出方案，不发送请求；含`--live`才执行所选一组。缺凭据或请求未完成退出2，有字段空缺/异常退出3，成功取得全部所选字段退出0。退出0仍不代表指标语义或评分已通过。Token读取本机.env或环境，不接受命令参数。

测试报告单独存SQLite的probe_reports，不会自动变成正式产品净值或评分证据；按当前凭据指纹读取最近10份。本机产品查询模板可解析最多100项，但应先分组实测，避免把未知/无权限字段一次加入日常查询。


## 分类查询与可用维度综合分更新

根据用户明确要求，空指标直接标注“无有效数据”，不再把更换样本、逐字段终端验证作为继续查询的前置条件。产品综合查询统一列出83项、12分类，按组读取，任何成功响应中的空字段不影响其他字段或已有评分。

新的“已覆盖维度综合参考分”是对已经有有效依据的维度重新归一化加权，与原有完整综合分并列而不混同。它公开有效权重比例和缺项；不把空值计0分，也不把真实0分排除。原有完整分的≥80%及核心维度要求继续保留。单纯单位净值恒定、原始数值有值但定义/口径不明，仍不编造评分。净值、规模、久期等输入指标不按数值高低直接评价优劣。

查询结果、分组游标及上下文存analysis_runs。空值继续；请求失败不等同“无有效数据”，单组失败保留原因并继续，连续三组失败暂停，未处理项保留“尚未查询”。原值及派生指标、数值可用率及评分权重覆盖率均分开。

本机截图已证明用户的接口和终端在该产品返回单位净值、另两列空白；此事实不作为其他字段不可用或全部权限有效的证据。自动检查使用隔离上游响应桩验证完整流程，不能声称云端已完成真实83项授权取数。
