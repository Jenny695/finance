# 新闻与 DeepSeek 定性研究

产品分析页新增独立的“新闻与定性研究”区域。用户填写代码和类别后，可使用产品目录名称检索近30/90天新闻；目录没有名称时补充完整基金名称，管理机构可选。不需要先完成量化查询。完成量化分析后，AI可结合该账号当前产品的量化摘要进行解读。

## 功能与证据

- 新闻检索优先使用Bing News公开RSS；未匹配到产品报道时补充东方财富公开网页的新闻检索结果（JSONP只作JSON解析，不执行脚本），不声称覆盖全网。以真实链接、来源名称和发布时间展示，剔除区间外、无日期、明显未来和不相关结果，按链接去重。
- 精确产品名称/基金份额家族匹配归“产品相关”；仅管理机构名称匹配归“管理机构相关”，不把机构事件归为旗下所有基金的事实。
- 对限定媒体域名与配置的官网读取公开HTML正文，检查公网DNS、HTTPS和robots，不跟随跳转，不绕过验证码/登录。每次最多读取4篇正文，其余显示RSS摘要；正文读不到也不会伪称已读。
- 默认正文来源包括东方财富、新浪财经、中国证券报、证券时报、上海证券报、经济参考报相关域名。额外官方域名可用`NEWS_SOURCE_HOSTS`或`PUBLIC_SOURCE_HOSTS`配置。网页不接受任意URL输入。
- 新闻缓存1小时，检索不可用/空结果缓存5分钟，减少反复请求；访问源站仍取决于当前网络、robots和源站结构。没有新闻不代表没有风险。
- AI四维：投资策略与风格、管理与治理、信息披露、事件与舆情。显示有利线索、关注风险、正反因素或资料不足，不将新闻情绪折算成收益承诺或修改量化综合分。
- 所有事实性说明要求证据编号和可逐字对应的引文。引用不通过检查时不展示该次AI结论。引用校验不是对报道本身真实性的独立核实；页面标为AI辅助解读，普通投资者可点击引用查看依据。

## 配置 DeepSeek

1. 在 DeepSeek 开放平台开通API并取得自己的密钥。账号、API访问及费用以DeepSeek实际规则为准，网页聊天会员不等于API额度。
2. 在原项目 `.env` 末尾添加，已有同名项时修改而不是重复添加：

```dotenv
AI_API_KEY=这里替换成你自己的DeepSeek密钥
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
```

3. 保存并重启网站后台。已有同花顺Token、管理员配置和数据库不变；不要公开或发送整个.env。
4. 云服务器放在 `.env.production`；Render/Hugging Face等放在平台Secrets/环境变量，AI_API_KEY使用Secret。
5. 本功能需更新`src`、`server`、`lib`并重新`npm run build`。可使用项目的`UPDATE-FINANCE.cmd`同步最新代码并重建；保留`.env`、`.public-data`和原始目录。

默认DeepSeek；也兼容`AI_BASE_URL`/`AI_MODEL`指定的OpenAI Chat Completions式HTTPS接口。密钥只在服务端Authorization Header使用，不发送浏览器、不进入模型提示词或原文链接。AI未配置时，新闻仍可独立使用，页面不会生成假AI结论。

## 使用流程

1. 在产品查询页填写代码、类别，可先查询量化分析。
2. 页面下方“新闻与定性研究”填写/确认完整产品名称，点击“检索相关新闻”。
3. 查看新闻日期、来源、产品/管理机构范围和正文/摘要标记。
4. 点击“生成AI解读”。此操作会把本次新闻证据与产品量化摘要发送至已配置AI服务，可能产生AI服务费用；不会发送账号、密码、Token、持仓金额或个人投资计划。
5. 阅读四维结论、有利线索与关注点，点击引文核查原文。缺乏证据的维度明确显示资料不足。

AI结果按账号隔离，1小时内相同新闻与量化摘要复用缓存。每账号每小时最多10次新的AI请求、全站100次；新闻新检索每账号每小时30次、全站300次。缓存命中不计这些次数，不占同花顺查询额度。失败不自动重试；无证据不调用模型。

本次开发不包含可用的真实AI密钥，因此自动化测试使用隔离的新闻与模型响应，不能声称已完成你账号的DeepSeek实时联调。真实新闻源和AI返回需在你运行网站的网络和账号下验证。
