# 知衡 · 理财持仓查询与分析原型

基于 HTML、Tailwind CSS、JavaScript 和 ECharts 的 PC 响应式网页原型。包含登录演示、持仓概览、产品七维分析、产品对比、数据源说明、个人中心。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前验证：24.19.0）及 npm。

```sh
npm ci
npm run dev -- --port 5173
```

构建：`npm run build`。预览构建产物：`npm run preview -- --port 4173`。

首页为访客演示，点击右上角“演示账户”进入登录页，也可访问 `/#/login`。任意非空昵称、至少六位演示密码并勾选风险提示即可登录。请勿输入真实金融账户凭证。密码不发送、不保存，仅 sessionStorage 保存昵称。所有账户使用相同的模拟持仓。

## 交互

- 产品类型筛选、名称搜索、金额隐藏、CSV 导出。
- 产品卡片跳转详情，净值图支持 1/3/6 月切换与缩放。
- 资产配置和底层资产图使用 ECharts，窄屏自动适配。
- 七维演示评分、专业名词 hover / 键盘聚焦解释、数据来源单独展示。
- 产品对比支持多选，至少两只；跨类型不生成排名。

## 模拟数据与真实来源的边界

首页、持仓和原产品详情中的四只产品、发行机构、金额、净值和评分均为虚构，分数为独立占位值。新增“数据评测”工作台使用独立输入和可复算模型，见下文；两种数据不混用。不得将合成数据用于投资判断。

同花顺 iFinD 与中国理财网链接仅是官方入口，不是演示产品的原文依据。没有真实发行机构或原始文件，因此不伪造文件链接，页面明确显示“原文未获取”。

## 数据评测工作台（新增）

导航点击 **数据评测**，进入 `/#/research`。这与首页的四只模拟产品互相独立，不会把合成持仓伪装成真实资产。

### Windows 本地体验

1. 从 GitHub 下载最新 ZIP 并解压。进入含 `package.json` 的那一层目录，地址栏输入 `cmd`。
2. 执行 `npm ci`，然后执行 `npm run dev`。保留命令窗口。
3. 在浏览器打开终端显示的 Local 地址，点击“数据评测”。
4. 点击“先用合成净值试算”，再点击“计算指标与评分”。这会使用合成净值与合成披露材料，覆盖85%默认权重并展示**模拟**参考综合分。
5. 分析真实产品：从 iFinD 客户端导出有权使用的历史净值 CSV（UTF-8），选择日期列和净值列。填写真实产品类型、风险等级、币种、费用及净值口径，并填写实际数据来源。单位净值有分红时必须先取得复权序列。
6. 依据原始说明书、报告与公告填写证据。结构见 `examples/evidence-template.json`。没有证据的维度留空，不填零分，也不复制合成材料。
7. 权重合计须为100%。点击计算，查看指标、来源、计算口径及模型参数。修改输入后报告会标记过期，需重算后才能导出。

CSV 支持表头映射（如“日期/净值”或“date/nav”），日期严格为 YYYY-MM-DD。拒绝重复日期、非正数、空值或混合产品；一次只导入一只产品。示例 CSV 在 `public/examples/demo-nav.csv`，仅供测试。

### 真实 iFinD HTTP API（尚未完成联调）

网页登录账号不代表 HTTP API 授权，也不能据此读取用户在银行或券商的个人持仓。官方提供免费版数据接口，但本账号能否提取具体理财指标仍需确认。先核对理财净值指标、历史区间、调用额度和网页展示授权；无接口权限可以先使用客户端 CSV 导出。

1. 按照官方 HTTP 示例，下载 Windows 接口包并解压，打开“超级命令 → 工具 → refresh_token 查询”。取得的凭据只在本机或环境安全设置填写，不要向聊天发送。
2. 本机将 `.env.example` 复制为 `.env`，填写 **IFIND_ACCESS_TOKEN** 或 **IFIND_REFRESH_TOKEN**。重启开发服务。禁止把凭据放到 `VITE_` 变量中。
3. 在同花顺官方代码生成器选择真实产品与净值指标，将其 JSON 参数（不含密码、Token、Cookie或请求头）复制到工作台，准确填写响应中的产品代码与净值字段。
4. 工作台通过本机后端向固定的官方地址 `https://quantapi.51ifind.com/api/v1/` 发送只读查询。支持的适配端点为 `date_sequence`、`basic_data_service`、`cmd_history_quotation`。字段名与响应解析必须用账号当前官方生成器及实际响应再次核对；未臆造默认的理财净值字段。
5. 当前解析 `tables[] -> thscode / time / table[选定字段]`。不识别的响应不会填零、不会转换成模拟数据；请核对接口或用 CSV。

**目前只验证了本机适配器与模拟上游响应，尚未验证真实账号的 API 授权、端点结构或产品覆盖。** 初次连接曾被代理403阻断；使用标准环境代理后，已成功读取 iFinD 官方HTTP示例、权限页及中国理财网公告，端点和鉴权方向已与官方示例核对。但这不证明账号授权；仍需安全配置官方Token并执行一次代表性查询。统一披露平台子域尚未成功访问。详见 docs/data-research.md。不要把这份代码描述为已连接真实 iFinD。

后端使用标准环境代理（HTTPS_PROXY / HTTP_PROXY / NO_PROXY），保持默认 TLS 校验，只通过官方域名发送 Token，不在响应或错误中返回凭据。当前为**本机单用户研究工具**，API 只接受 localhost/127.0.0.1 主机名及同源请求。未实现真实多用户权限隔离，不能直接作为公网金融平台部署。不要使用 `vite --host` 暴露本机真实凭据给他人。

### 公开披露信息读取

“公开原文读取”支持输入单篇已知的官方 HTML/文本原文地址。默认域名为 `www.chinawealth.com.cn` 与 `www.51ifind.com`。发行机构域名需先人工确认，再在 `.env` 的 `PUBLIC_SOURCE_HOSTS` 中按逗号分隔配置并重启服务。

- 仅读取具体原文，不递归遍历网站、不登录、不绕过验证码、不绕过站点限制。
- 检查 robots，读取失败或禁止时停止；保守解析可能拒绝允许规则，遇到此情况请人工查看。
- HTTPS、域名白名单、私网地址拒绝、禁止重定向、请求间隔、超时与文件大小限制。
- 目前不支持 PDF 自动解析、GBK编码识别、自动匹配产品、自动抽取/核验净值或跨站点自动找产品。
- 取得原文文本仍标为未核验，人工核对后才可录入模型证据。官网主页不是产品原文。

### 模型定义与评分边界

模型版本：`zhiheng-research-1.0`，实现见 `lib/assessment.js`。

|维度|默认权重|计算方法|
|---|---:|---|
|收益表现|20%|年化收益在产品类型预设区间内线性映射，截断至0—100|
|风险回撤|25%|最大回撤60% + 年化波动40%，按类型风险阈值扣分|
|底层资产透明度|10%|有原文证据的可穿透比例，不将债券比例等同安全性|
|流动性|10%|锁定天数、到账天数、开放频率规则化扣分|
|机构资料完整度|5%|许可、登记、年度报告三项材料完整度；不评机构信用|
|信息披露质量|15%|说明书、定期报告、赎回规则、费用、按时披露各20分|
|同类横向对比|15%|至少5只严格同口径去重样本的区间收益百分位，同值取中位秩|

收益区间、回撤阈值、波动阈值、流动性扣分均为**公开的自建参数**，不是行业标准或经回测验证的评级。不同类型使用不同参数，不跨类型排名。机构和披露维度需要人工证据确认，代码不会作出“监管合规已核验”或“偿付安全”结论。

综合分 = 有效维度的(分数×权重)合计 / 有效权重合计。有效权重覆盖至少80%，且收益、风险、披露三项均有效且权重大于0，才展示参考综合分；否则仅展示已覆盖维度参考分和覆盖率。未覆盖维度不会以零分处理，也不凭空补分。资料真实性仍需独立核验，达到覆盖门槛不等于已核验。

净值指标使用同一输入序列计算：

- 区间收益：末值/初值−1。
- CAGR：(末值/初值)^(365.25/实际天数)−1。
- 最大回撤：区间内 max(1−当期净值/此前最高净值)。
- 年化波动：简单收益样本标准差×√年化期数。
- 下行偏差：√(负区间收益平方和/全部收益区间数×年化期数)。
- 夏普近似：(CAGR−输入无风险年利率)/年化波动；此CAGR近似不等同标准算术超额收益夏普。
- 年化需至少90天、30条观测及频率校验通过；年化期数由用户选252/365/52/12。零波动不出夏普，采样不符不出年化，不插值缺失净值。
- 同类样本严格匹配类型、风险等级、起止日期、币种、费用与净值口径；代码去重，不能纳入本产品本身。
