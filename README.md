# 知衡 · 理财持仓查询与分析原型

基于 HTML、Tailwind CSS、JavaScript 和 ECharts 的 PC 响应式网页原型。包含登录演示、持仓概览、产品七维分析、产品对比、数据源说明、个人中心。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前验证：24.19.0）及 npm。

```sh
npm ci
npm run dev -- --port 5173
```

构建：`npm run build`。预览构建产物：`npm run preview -- --port 4173`。

首页为访客演示，点击右上角“演示账户”进入登录页，也可访问 `/#/login`。任意非空昵称、至少六位演示密码并勾选风险提示即可登录。请勿输入真实金融账户凭证。密码不发送、不保存，仅 sessionStorage 保存昵称。所有账户使用相同的模拟持仓。

## 交互

- 产品类型筛选、名称搜索、金额隐藏、CSV 导出。
- 产品卡片跳转详情，净值图支持 1/3/6 月切换与缩放。
- 资产配置和底层资产图使用 ECharts，窄屏自动适配。
- 七维演示评分、专业名词 hover / 键盘聚焦解释、数据来源单独展示。
- 产品对比支持多选，至少两只；跨类型不生成排名。

## 模拟数据与真实来源的边界

所有产品、发行机构、金额、净值和评分均为虚构。统计指标是独立示例值，与合成净值曲线不具有计算对应关系；综合分为独立占位值，没有实际评估含义。不得用于投资判断。

同花顺 iFinD 与中国理财网链接仅是官方入口，不是演示产品的原文依据。没有真实发行机构或原始文件，因此不伪造文件链接，页面明确显示“原文未获取”。

## API 对接预留

`src/data.js` 中的 `api.getHoldings()`、`api.getProductAnalysis(id)` 是替换点；详情页已通过异步适配接口获取演示数据。

生产环境应由后端调用获得授权的同花顺 iFinD 接口，不在浏览器中嵌入密钥。不要将平台演示登录作为真实身份认证。需实现后端鉴权、账户级持仓权限和隐私保护。

生产指标应包含：

```js
{
  value: 0.0342,
  unit: 'ratio',
  asOf: 'YYYY-MM-DD',
  sourceUrl: '实际原始披露文件的 HTTPS 地址',
  documentTitle: '实际文件名',
  publishedAt: '真实发布日期',
  retrievedAt: '实际检索时间',
  methodology: '计算区间、费用、复权方式、模型版本',
  status: 'verified' // 无原始证据时使用 unavailable，不补造指标
}
```

真实 API、账号体系、数据库、自动抓取和实际评分模型不属于此原型。所有第三方库由 npm 安装并在本地构建，不依赖运行时 CDN。
