# 知衡 · 理财产品查询与研究平台

面向普通投资者的本机网页应用：产品查询、净值与风险图表、可解释的七维研究模型、产品对比、来源追溯，以及首次数据接入配置。HTML + Tailwind CSS + JavaScript + ECharts，Vite 同时提供本机数据 API。

## Windows 开始使用

需要 Node.js **22.12+**（已验证24.19.0）和 npm。

1. 从 GitHub 下载最新版 ZIP 并解压，进入含 `package.json` 的那一层目录。
2. 如果旧项目已配置 Token，仅在自己电脑把旧 `.env` 复制到新项目根目录。不要发送聊天或上传 GitHub。
3. 在该目录地址栏输入 `cmd`，运行：

```sh
npm ci
npm run dev
```

在浏览器打开终端显示的 Local 地址。保持终端运行。构建 `npm run build`，生产产物本机预览 `npm run preview`，自动检查 `npm test`。

服务默认绑定127.0.0.1；API同时检查远端地址、Host和Origin，只供本机单用户研究。尚未实现公网多用户权限隔离，不直接作为公网金融平台部署。

## 普通用户查询流程

1. 首页“产品查询”支持名称、机构、代码搜索，产品类别与风险筛选、关注、2—4只产品对比。
2. **演示体验**：4只产品均为合成数据。净值图、收益、风险和七维评分使用相同序列重新计算，不使用原先的固定占位评分。对应原持仓页为演示，不是用户实际银行持仓。
3. **我的 iFinD 数据**：使用本机 `.env` 里的 Token 与类别净值模板。配置了凭据时首次默认进入该模式；可手动切换回演示。模式间不会混合对比或失败回退。
4. 银行理财已预置用户从官方超级命令提供的字段：

```python
THS_DS('YH0000434.YH','ths_unit_nv_fund','','block:latest','2026-09-16','2026-10-16')
```

完整代码是 **`YH0000434.YH`**（不是早期截图中误读的较短代码）。平台用 `date_sequence`，单位净值字段 `ths_unit_nv_fund`，请求参数保留 `block:latest`，但缺失值处理强制 `Fill:Blank`。日期由网页选择，自动转换为官方日期序列格式。

5. 点击预置产品，或在“我的 iFinD 数据”输入该完整代码，选择区间，点击“查询并分析”。一次显式操作发起一次授权查询，可能消耗额度。缓存5分钟，相同并发请求复用，不自动重试；错误时不显示伪造的真实数据。
6. 产品页展示净值走势、最大回撤、年化换算、波动、七维评分、通俗说明及具体来源。真实资产和赎回原文未取得时保留空白，不猜测资产比例或到账安排。合成样本提供底层资产饼图与赎回规则用于体验。
7. 当前仅预置一条来自用户截图的目录信息，名称也标记待核对。**这不是iFinD全市场产品目录。** 真实名称搜索仅覆盖已导入目录；知道准确代码时可按配置好的类别模板直接查询。

## 首次连接与扩展类别

### 本机凭据

将 `.env.example` 复制为 `.env`，填写 `IFIND_REFRESH_TOKEN` 或 `IFIND_ACCESS_TOKEN`，然后重启服务。不使用 `VITE_` 前缀变量；不接收账号密码作为HTTP Token。Token只由后端向官方 `quantapi.51ifind.com` 发送，不返回浏览器或写入目录文件。

[官方 Windows 接口包](https://quantapi.51ifind.com/gwstatic/static/ds_web/quantapi-web/download.html)解压后：超级命令 → 工具 → refresh_token 查询。网页登录账号不等于所有数据权限。用户已提供本机股票行情查询成功的截图；银行理财字段已由官方生成函数确认，**真实银行理财净值响应仍需在用户本机验证**。云工作区没有用户本机Token，不声称已完成云端授权取数。

### 类别净值模板

进入“数据连接”。银行理财已预置单位净值模板，其他公募基金、券商资管、信托、其他资管类别可独立添加模板；不能假设一个字段覆盖所有类别。

从官方超级命令选一只该类别产品和一个真实净值指标，选择“不运行，输出请求函数”，复制 **THS_DS六字符串参数函数** 到页面，点击“识别官方查询函数”。确认净值口径、分红、费用、采样频率后保存。解析器不执行代码，不接受登录函数、密码或Token。高级入口保留官方HTTP JSON配置。

未知分红时单位净值不作为总回报评分。预置银行模板的费用、币种、采样与分红还未核对，`basisConfirmed:false`，只展示净值及指标，不擅自生成研究分。保存模板必须对照原文确认相关口径。

### 名称搜索的产品目录

“数据连接”可导入官方产品目录 CSV（UTF-8，单次1.5MB/最多10000只，支持分批upsert）。在网页映射代码、名称、机构等列。名称和代码必填；未知风险、币种、资产分类留空。不会自动把银行理财设为固定收益或R2。

示例列结构：

```csv
code,name,issuer,type,riskLevel,currency
```

`type` 仅接受 `fixed/mixed/cash/equity`，`riskLevel` 仅接受 `R1—R5`；可不导入可选列。类别在上传时选择，同一批应属于同一类别。目录和模板仅存本机 `.local/catalog.json`，Git忽略该目录及 `.env`，发布代码不会包含这些私人配置。首次配置后查询无需再填写JSON。

## 评分模型：公开、可复算、有边界

版本 `zhiheng-research-1.0`。页面“评估方法”公开全部模型假设，详情页每项展示公式、权重、证据和缺项。客观计算不代表评分标准是唯一正确的标准。

|维度|默认权重|方法与必需资料|
|---|---:|---|
|收益表现|20%|CAGR按产品类型预设区间映射；须有有效净值及分红费用口径|
|风险回撤|25%|最大回撤60% + 年化波动40%，以公开类型阈值扣分|
|底层资产透明度|10%|报告有证据支持的可穿透比例；不把债券比例等同安全性|
|流动性|10%|持有天数、到账时间、开放频率及原文|
|机构资料完整度|5%|许可、登记、年度报告三项完整度；不评偿付能力|
|信息披露质量|15%|说明书、报告、赎回规则、费用、及时性五项|
|同类横向对比|15%|至少5只类型、风险、日期、币种、净值费用口径相同的去重样本|

综合分 = Σ(有效维度分×权重) / 有效权重合计。有效权重至少80%，且收益、风险、披露有效并为正权重，才展示参考综合分。否则展示覆盖率、局部维度分与缺失原因。不把局部高分冒充完整评价。

收益区间、风险阈值与流动性扣分是公开自建参数，不是行业评级标准，未作预测有效性验证。不同类型不直接排名。未知类型、风险、币种、分红口径不擅自补齐。**仅有净值通常无法生成完整综合分**，非净值维度还需要原始披露与同类样本。

- 区间净值变化：末值/初值−1，不复权时不含分红再投资。
- CAGR：(末值/初值)^(365.25/实际天数)−1。
- 最大回撤：max(1−当期净值/此前最高净值)。
- 年化波动：简单收益样本标准差×√年化期数。
- 下行偏差：√(负区间收益平方和/全部区间数×年化期数)。
- 夏普近似（高级工作台）：(CAGR−输入无风险年利率)/波动率，不等同标准算术超额收益夏普。
- 年化至少90天、30条有效观测和频率校验；年化252/365/52/12按真实采样选择。短样本、零波动和频率不一致按规则停止相关计算。
- 空观测不填0、不沿用前值；查询页可过滤空观测并明确计数，过长缺口会使频率校验失败。CSV和高级解析默认严格拒绝空值。

## 高级研究与公开原文

`/#/research` 保留CSV净值导入、按列映射、人工来源确认、权重设置与报告导出。可用 `examples/evidence-template.json` 和 `public/examples/demo-assessment.json` 查看证据结构；合成材料不能用于真实结论。股票`close`联调数据禁止按理财净值评分。

公开原文读取仅针对已知官方HTML/文本，不绕过验证码、不递归爬取，保持TLS、robots、白名单、私网拒绝、限频和大小限制。PDF自动解析、自动匹配产品原文、全市场目录自动发现均尚未实现。更多来源核查见 `docs/data-research.md`。

## 主要接口

|接口|作用|
|---|---|
|GET /api/connection|仅返回配置是否存在、模板字段与目录数量，不返回凭据|
|GET /api/products?search=&category=&risk=&page=|本机产品目录搜索、筛选与分页|
|POST /api/products/query|按代码、类别、起止日期取净值、计算指标与条件评分|
|POST /api/products/import|导入/更新本机产品目录|
|POST /api/templates|验证并保存类别净值模板|
|POST /api/ifind/query|高级官方只读查询适配器|
|POST /api/public/disclosure|单篇官方原文读取|

`lib/assessment.js` 为评分模型；`lib/catalog.js` 为目录与模板校验；`lib/template-import.js` 为安全函数解析器；`server/product-service.js` 为目录持久化和查询/缓存服务；`src/portal.js`、`src/portal.css` 为新查询界面。

## 验证与限制

`npm test` 覆盖公式基准、数据缺失、分红、权重、同类样本、CSV、凭据边界、公开来源、目录、模板、缓存与并发。浏览器检查覆盖搜索筛选、关注、对比、图表、导出、日期失效、配置与移动布局。真实iFinD联调不能用模拟上游测试替代。

真实登录、银行/券商个人持仓、交易、全自动披露证据采集和公网多用户服务尚未实现。公开数据再分发需确认来源授权。**不构成任何投资建议，过往业绩不预示未来表现，投资有风险。**
