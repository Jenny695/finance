# 知衡 · 投资研究平台

面向普通投资者的产品查询、七维研究、同类对比和投资知识网站。真实服务端注册登录，个人报告与投资计划按账户隔离；管理员的数据配置与普通页面分开。

普通导航：**首页、产品查询、产品对比、投资知识、个人中心**。不提供演示持仓、虚构产品、风险等级筛选或无数据的“其他资管”选项。

## 免费体验：Hugging Face Spaces

已适配Docker Space的7860端口、非root运行和平台HTTPS地址。只需在Space根目录添加[部署Dockerfile](deploy/huggingface/Dockerfile)和[Space配置README](deploy/huggingface/README.md)，按[免费体验部署教程](docs/huggingface-deployment.md)设置秘密变量。免费实例可能休眠，重建可能清空账号和目录；此方案适合体验，不承诺数据持久保存。

## 无法绑定托管平台付款卡：独立云服务器

已提供 Docker Compose + Caddy 配置，服务器后台运行、持久保存账号和目录、自动申请HTTPS证书，Windows电脑关机后网站仍可访问。准备自己的云服务器和域名后，按[云服务器部署教程](docs/cloud-server-deployment.md)操作；服务器与域名费用以平台结算页为准。

## 给他人使用：一键托管

[在 Render 创建网站](https://render.com/deploy?repo=https://github.com/Jenny695/finance)

使用GitHub账号注册/登录Render，按仓库`render.yaml`创建网站，完成后分享平台生成的HTTPS地址。配置为带持久磁盘的付费单实例，费用以Render确认页为准。没有账号时无法由聊天直接生成长期托管网址；部署入口不是已经上线的网站。

详细步骤见[公网部署说明](docs/public-deployment.md)。iFinD Token填写在托管平台的保密环境变量中，普通用户页面不会要求输入Token。公网初始数据库不复制本机`.local`、原始导出文件或私人报告。管理员可导入准备用于网站的产品目录。

## Windows 本机启动

需要Node.js 24 LTS（最低22.12）。下载源码并解压到包含`package.json`的目录，双击`启动网页.bat`或`start-finance.cmd`；保持窗口运行。也可执行：

```sh
npm ci
npm run dev
```

首次使用注册真实平台账号。旧的演示昵称不是账户。升级保留`.env`、整个`.local`和`import-files`，但旧单用户研究记录不会自动展示给新注册的其他用户。

管理员：在本机`.env`设置ADMIN_USERNAME和ADMIN_PASSWORD（至少8位），运行`npm run create-admin`，再登录该账号。不要把密码放进命令行参数、聊天或GitHub。普通注册用户始终为投资者角色。

## 产品与分析

- 产品类别：银行理财、公募基金、券商资管、信托。目录只代表已导入范围，不代表全市场数据已同步。
- 31项字段、8类9组有界请求，使用服务端iFinD授权；空值不补零、不自动重试。未配置数据源时不展示虚构行情。
- 七维研究：收益20%、回撤20%、稳定15%、风险收益效率15%、下跌防御10%、回撤修复10%、费用10%。缺失维度跳过，真实0分保留。
- 额外分析：多期变化、当前回撤/修复观察期、历史VaR/ES、滚动体验、同类统计参照、资产配置。
- 决策参考：自设风险预算、持有期限、仓位上限和退出条件。高分不覆盖约束，不设单一分数自动买卖指令。
- 同区间报告优先读取；修改投资计划不调用上游。统计单位与模板等工具仅管理员可用。计算、来源和模型边界见[研究规则](docs/simple-scoring.md)。

产品查询与对比共用分析流程，不再要求普通用户配置类别模板。数据未披露或字段不适用时隐藏空项；官方统计保留自己的参数/窗口，不混成相同观察期。

## 账户与数据

密码使用scrypt加盐哈希；会话使用随机令牌，数据库仅存令牌哈希。公网Cookie为Secure、HttpOnly、SameSite=Lax；写请求校验同源。注册、登录、查询均有限频，个人记录和对比选择隔离。默认中国标准时间每天每用户240次、全站240次普通分析分组请求，可由管理员调整。

开发数据库`.local`；公网默认`.public-data`或DATA_DIR指定的持久目录。账户在`accounts.sqlite`，产品与报告在`finance.sqlite`。全部为私有运行文件，不提交Git或打入Docker镜像。

原始目录准备器与旧高级批量同步保留供管理员使用。`.xlsx`/CSV批量导入和目录分类仍支持此前四类原文件；新增公网数据库需由管理员主动导入。个人银行/券商账户持仓和真实交易不在本项目接入范围内。

## 部署与验证

```sh
npm test
npm run build
npm start
```

生产服务使用PORT、PUBLIC_URL（HTTPS）和DATA_DIR；Render自动提供HTTPS来源变量。Docker按`Dockerfile`构建，持久目录为`/var/data`。`/healthz`用于健康检查；公开服务只提供构建产物和经过登录/权限校验的API，不暴露本机原始文件。

临时体验链接只在对应进程在线期间有效，不能替代长期托管。真实iFinD覆盖和权限需以部署后账号实际响应验证；自动化联调使用隔离的模拟上游，不冒充真实查询。
